## elden-ring-weapon-calculator

<https://github.com/ThomasJClark/elden-ring-weapon-calculator>

Used for:

- `data/raw/regulation-vanilla-v1.17.json` and its copy at `src/data/regulation.json` —
  Elden Ring regulation data (weapon base attack, scaling coefficients, upgrade
  multipliers, calc-correct graphs, status effect parameters), extracted from the
  game using WitchyBND.
- `src/calculator/attack-power.ts` — a port of that project's attack-power
  calculation and regulation-data decoding.
